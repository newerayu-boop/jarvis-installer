# Silicon Valley Girl (Marina Mogilko) — методология YouTube-канала (полный разбор 100 видео)

Разбор методологии канала Silicon Valley Girl (https://www.youtube.com/@SiliconValleyGirl; бизнес-идеи, AI, карьера, интервью с фаундерами) на основе транскрибаций **топ-100 видео по просмотрам** и анализа упаковки **всех 358 видео** канала. Сделан по тому же пайплайну, что и разбор Jeff Su (`../jeff-su-youtube-methodology/`).

Цель: база знаний для проекта в Claude, чтобы создавать собственные YouTube-видео и подкаст-интервью по проверенной методологии.

## Как загрузить в проект Claude

1. Ядро: все файлы из `methodology/` + `videos-index.md`.
2. По необходимости: `analysis/` (детальные разборы) и выборочные `transcripts/` как эталоны под вашу тему.
3. Пример инструкции проекта:
   > Ты — сценарист моего YouTube-канала и подкаста. Пиши хуки, структуры, сценарии и вопросы для интервью по методологии Silicon Valley Girl из базы знаний: цифра-шок/деньги в первых 20 секундах, нумерованный листикл с ранжированием по возрастанию, конкретные суммы в каждом блоке, спонсор только в середине через нативный мостик, финал с заданием в комментарии и мостом на следующее видео. Для интервью — тизер-нарезка, представление гостя цифрами, вопросы от лица новичка, ритуальный блиц в конце. Адаптируй под мою нишу, не копируя примеры дословно.

## Формула канала (кратко)

- **Хук**: конкретная сумма денег или шок-статистика + дедлайн в первых 2 предложениях; в интервью — cold open-нарезка цитат гостя.
- **Каркас соло**: нумерованный листикл, каждый пункт = тезис → личная/звёздная история → цифра → action step; лучшее придерживается на конец (open loop).
- **Каркас интервью**: тизер → регалии гостя цифрами → «60 seconds intro» → вопросы от боли аудитории → демо → блиц → мост на другой эпизод.
- **Удержание**: деньги в каждом блоке, «watch up to the very end», финансовая прозрачность, личная уязвимость.
- **Монетизация**: спонсор в середине через мостик «инструмент, которым я сама пользуюсь» + промокод; рефералки; курсы с дефицитом; newsletter с чек-листами.
- **Упаковка**: число + $ + год в заголовке; соло 15–20 минут; интервью-формула «Meet a [возраст]-year old from [страна] running a $[сумма] company» / «$[valuation] AI CEO: [провокация]».

## Как собран датасет

Транскрибации — из субтитров YouTube (yt-dlp); 5 видео из топ-100 не имели субтитров и заменены следующими по просмотрам. Каждое видео разобрано по единой схеме с дословными цитатами; упаковка проанализирована статистически по всем 358 заголовкам; воронка — по ссылкам из 105 описаний.
