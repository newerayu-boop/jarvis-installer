## 🔴 Блокеры — чинить до выдачи

### 1. Установщик принимает ключи-заглушки из примера

**Где:** `install.sh`

**Что произойдёт у ученика:** Ученик скопировал jarvis.env.example, ничего не поменял, и установка прошла «успешно». Бот установится и будет молчать. Ученик напишет: «всё установилось, но бот не отвечает» — и вы будете искать причину вслепую.

**Как чинить:** Проверять формат каждого ключа: TELEGRAM_TOKEN по маске ^[0-9]{8,10}:AA, OPENROUTER_KEY по ^sk-or-v1-, GROQ_KEY по ^gsk_, OWNER_TELEGRAM_ID только цифры. И явно ругаться на значения с 'xxxx'.

## 🟠 Серьёзные — сломается у части учеников

### 2. Нет проверки на root

**Где:** `download.sh`

**Что произойдёт у ученика:** Скрипт выполняет системные команды, но не проверяет, что запущен от root. Ученик запустит без sudo и получит гору 'Permission denied'.

**Как чинить:** Добавить в начало: [ "$EUID" -ne 0 ] && { echo 'Запусти: sudo bash download.sh'; exit 1; }

### 3. shellcheck нашёл проблемы

**Где:** `install.sh`

**Что произойдёт у ученика:** /home/user/jarvis-installer/install.sh:64:20: warning: Quote this to prevent word splitting. [SC2046] /home/user/jarvis-installer/install.sh:65:29: warning: Quote this to prevent word splitting. [SC2046]

**Как чинить:** Разобрать вывод shellcheck: install.sh

### 4. Захардкожен путь к глобальным node_modules

**Где:** `install.sh`

**Что произойдёт у ученика:** 230:MEDIA_JS=$(find /usr/lib/node_modules/openclaw/dist -name "media-understanding.runtime-*.js" 2>/dev/null | head -1) 

**Как чинить:** Использовать $(npm root -g) вместо жёсткого пути — иначе на части VPS файл не найдётся.

### 6. Инструкция ссылается на отсутствующий файл: extras/google-calendar.md

**Где:** `README.md`

**Что произойдёт у ученика:** В тексте есть путь 'extras/google-calendar.md', но такого файла в репозитории нет. Ученик пойдёт туда и не найдёт ничего.

**Как чинить:** Создать extras/google-calendar.md или убрать упоминание.

### 7. Команда логов не сработает у ученика

**Где:** `README`

**Что произойдёт у ученика:** 'journalctl --user-unit=...' от root показывает логи root, а сервис крутится под другим пользователем. Ученик увидит пустоту и решит, что бот мёртв.

**Как чинить:** Дать команду вида: journalctl _UID=$(id -u aibot) -u openclaw-gateway -n 50  — или su под нужного пользователя.

### 8. Принимается @username вместо числового ID

**Где:** `install.sh`

**Что произойдёт у ученика:** Очень частая ошибка новичка: в OWNER_TELEGRAM_ID он пишет свой @ник. Установка пройдёт, но бот не узнает хозяина.

**Как чинить:** Проверять: [[ "$OWNER_TELEGRAM_ID" =~ ^[0-9]+$ ]] иначе подсказать «нужно число из @userinfobot, не @ник».

### 9. Пробел в начале токена не отлавливается

**Где:** `install.sh`

**Что произойдёт у ученика:** При копировании из Telegram часто прилипает пробел или перевод строки. Бот не запустится, ошибка будет только в логах.

**Как чинить:** Обрезать пробелы: TELEGRAM_TOKEN=$(echo "$TELEGRAM_TOKEN" | xargs) — и проверять маску.

### 10. Продавец напишет «Ism Familiya #13» — бот ответит «не понял»

**Где:** `ticket-platform/lib/messages.js`

**Что произойдёт у ученика:** Случай: номер со знаком #. Формально ученик виноват, но писать он будет именно так, и придёт жаловаться вам.

**Как чинить:** Расширить парсер: убирать #, принимать порядок «номер имя», чистить тире. Либо в ответе «не понял» показывать пример правильного ввода.

**Как чинить:** Починить регулярку разбора и закрыть случай тестом.
