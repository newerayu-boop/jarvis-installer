# Чем ломать продукт

Список проверок, которые нужно прогнать по каждому месту, куда ученик что-то вводит
или откуда что-то запускает. Проверяй руками, не по памяти.

## Ввод текста (бот, форма, поле)

| Что подать | Что ищем |
|---|---|
| пустая строка, только пробелы | падение вместо подсказки |
| одно слово | понятная ли ошибка |
| 4000 символов | обрезка, таймаут, падение |
| только цифры, только эмодзи | падение регулярки или рендера |
| кириллица + латиница вперемешку | битые шрифты, кракозябры |
| узбекские апострофы: `O'g'li`, `G'ofur` | съеденные символы |
| двойные пробелы, табы, перенос строки | кривой разбор |
| `\r` в конце (файл из Windows) | битые значения из конфига |
| `<script>`, `'; DROP`, `../../etc/passwd` | подстановка без экранирования |
| текст в другом порядке: `13 Имя` вместо `Имя 13` | «не понял» вместо результата |
| знаки, которые человек добавит сам: `#13`, `№13`, `- 13` | «не понял» вместо результата |

## Конфиги и токены

- Значение осталось заглушкой из примера (`xxxx`, `change-me`).
- Токен с лишним пробелом или переносом в начале/конце.
- Токен в кавычках-ёлочках `«»` вместо обычных.
- Числовое поле заполнено текстом (`@username` вместо ID).
- Файл сохранён в кодировке Windows-1251 вместо UTF-8.
- Обязательное поле пустое.

## Запуск и установка

- Запуск без sudo / от неправильного пользователя.
- Запуск дважды подряд.
- Прерывание на середине (Ctrl+C) и повторный запуск.
- Другая версия ОС и другая версия Node/Python.
- Нет интернета или он рвётся посреди установки.
- На диске мало места.
- Порт уже занят.

## Сеть и внешние сервисы

- API отвечает 401 (отозванный ключ), 429 (лимит), 500, таймаут.
- Кончились кредиты на балансе.
- Ученик не в белом списке доступа.
- Вебхук зарегистрирован на старый адрес.

## Картинки и рендер

- Очень длинное имя — вылезает за границы.
- Очень короткое — дырка в макете.
- Имя из одной буквы, имя из трёх слов.
- Эмодзи в имени — шрифт без эмодзи даёт пустой квадрат или падение.
- Проверять **глазами**: открыть файл, а не только убедиться, что он создался.

## Инструкция

- Выполнить каждую команду дословно, ничего не додумывая.
- Проверить, что каждый упомянутый файл существует.
- Проверить, что после каждого шага понятно, получилось или нет.
- Найти шаги, где ученик не поймёт, что делать дальше.
