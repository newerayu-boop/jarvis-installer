# Jeff Su — методология YouTube-канала (полный разбор 100 видео)

Разбор методологии Jeff Su (https://www.youtube.com/@JeffSu, ~2 млн подписчиков; продуктивность, AI-инструменты, карьера, экс-Google) на основе транскрибаций **топ-100 видео по просмотрам** и анализа упаковки **всех 192 видео** канала.

Цель: база знаний для проекта в Claude, чтобы создавать собственные YouTube-видео по проверенной методологии.

## Как загрузить в проект Claude

1. Создайте проект в Claude (claude.ai → Projects → New project).
2. Загрузите в Project knowledge в первую очередь: все файлы из `methodology/` и `videos-index.md` — это ядро.
3. При необходимости добавьте файлы из `analysis/` (детальные разборы с цитатами) и отдельные транскрибации из `transcripts/` как примеры-эталоны (все 100 могут не поместиться в лимит знаний проекта — выбирайте видео, ближайшие к вашей теме).
4. В инструкции проекта (Project instructions) можно написать, например:
   > Ты — сценарист моего YouTube-канала. Пиши хуки, структуры и сценарии по методологии Jeff Su из базы знаний проекта: ценность в первые 10 секунд, roadmap, нумерованный листикл с Pro tips, спонсор/CTA только в середине через смысловой мостик, финал-воронка на следующее видео. Адаптируй под мою нишу и язык, не копируя примеры дословно.

## Формула канала (кратко)

- **Хук до приветствия**: провокация / статистика / cold open-скетч / демо результата → план видео ("In this video I'll first… then…") → "Let's get started".
- **Каркас**: нумерованный листикл (3–10 пунктов), каждый пункт = проблема → живое демо на реальных данных → "Pro tip" → мостик дальше.
- **Удержание**: open loops, награда за досмотр, самоирония про корпоративную жизнь, гипер-конкретные цифры.
- **Монетизация**: только в середине, через нативный мостик "Speaking of…", с формулой доверия; лестница: бесплатный шаблон → рассылка → курс.
- **Финал**: рекап → увод на конкретное следующее видео → "See you on the next video. In the meantime, have a great one."
- **Упаковка**: измеримое обещание («Learn 80% of X in N minutes»), скобка-уточнение, 10–13 минут, массовая тема с нулевым порогом входа.

## Как собран этот датасет

Транскрибации получены из субтитров YouTube (yt-dlp) и очищены; каждое видео разобрано по единой схеме (хук / структура / удержание / спонсор-CTA / финал / фирменные фишки) с дословными цитатами; упаковка проанализирована статистически по всем 192 заголовкам (формулы, триггеры, длительность, кластеры тем vs просмотры).
